# 课标填空练习（42 题版工具站）

义务教育数学课程标准（2022 年版）填空题练习，单文件 HTML，离线可用，可放 GitHub Pages。

## 文件
- `quiz_data.json` —— 题库（build_quiz.py 从 docx 生成）
- `index_template.html` —— 页面模板（CSS + 交互逻辑，含 `__DATA_JSON__` 占位符）
- `make_site.py` —— 把题库注入模板，生成 `index.html`
- `index.html` —— 生成的成品（部署用这个）

改题库或改模板后执行：`python make_site.py`

## 功能
1. **练习**（填空作答）
   - 二级筛选：全部 40 题 / 乱序 / 练习 1·4·5·6 / 待练错题
   - 一题一屏，上一题 / 下一题
   - 全部空格填完后自动判分（也可点“检查”或按回车）
   - 判错立刻在错空下方显示正确答案，整题参考答案可点“整题答案”展开
   - 近似判分：去标点、忽略大小写，相似度 ≥0.8 或只差一个字算“近似”（黄框，算对）
2. **错题本**（按账号独立）
   - 做错的题自动进错题本，记录错次、最近一次的错误答案 → 正确答案
   - “开始重练”只抽未掌握的错题；连续答对 2 次自动标记“已掌握”
   - 可单练、可手动移除
3. **测试**
   - 选范围（全部 / 某练习 / 错题本）+ 题数 → 生成试卷
   - 一题一屏 + 答题卡，可自由跳题回改
   - 交卷按“空”计分（百分制），显示分数、正确空数、错题清单（含每空对照）
   - 测试错题自动进错题本；保留最近 40 次成绩
   - 进行中的试卷会保存，刷新不丢
4. **账号（登录制）**
   - 打开页面先出现**登录页**：选账号 → 输口令 → 进入；不登录看不到题目
   - 预置“账号一 / 账号二”，首次登录会强制设置口令（至少 4 位），之后每次进入都要输
   - 登录状态只在当前标签页有效：**关掉浏览器就退出**，下次打开必须重新选账号登录 —— 这样不会因为忘记切换而把成绩记到别人名下
   - 右上角账号按钮：退出登录 / 切换账号 / 新建账号 / 改口令 / 改名 / 导出数据（同步码）/ 导入数据
   - 口令只保存在本机（不可找回）；忘记口令时用另一台设备导出的同步码“导入数据”还原

## 数据与迁移
- 存储键：`kebiao_quiz_v2`（结构见代码顶部注释）
- 旧版 `kebiao_quiz_v1` 数据首次打开会**自动迁入“账号一”**，并把原文备份到 `kebiao_quiz_v1_backup`（不删除，可回退）
- 数据只存在本机浏览器；换设备用「导出数据 → 导入数据」搬运

## 部署
把 `index.html` 推到 GitHub 仓库根目录，开 Pages 即可。
