# 数学课标练习 · 填空题

面向手机使用的《义务教育数学课程标准（2022 年版）》填空题练习网页，共 **4 组 40 题**（练习 1 / 4 / 5 / 6）。纯静态单文件，`index.html` 双击即可用，也可托管在 GitHub Pages。

在线地址：https://hrxllzx.github.io/kebiao-quiz/

## 功能

- **答题模式**：题目中的空格直接点进去填写，点「检查」即时判分；答错会显示正确答案，答对显示 ✓
- **背诵模式**：一屏一题，轻点卡片显示整句答案，左右滑动或键盘 ←/→ 切换，适合通勤时快速过一遍
- **模糊判分**：忽略空格、标点差异；写法接近（如漏字）判为“基本正确”并提示
- **分组筛选**：全部 40 题，或只看某一组
- **自动保存**：作答记录、最后位置、模式都存本地（localStorage），关掉浏览器再打开还在
- **深色模式**：跟随系统自动切换
- **离线可用**：无任何外部依赖、无 CDN、无网络请求

## 使用

1. 手机浏览器打开 https://hrxllzx.github.io/kebiao-quiz/
2. 想加到桌面：Safari「分享 → 添加到主屏幕」/ Chrome「菜单 → 添加到主屏幕」，之后像 App 一样全屏打开
3. 点「答题 / 背诵」切换模式；顶部标签切换练习组；底部显示已做、正确、错误数量，右侧可清空记录

## 目录结构

| 文件 | 说明 |
|---|---|
| `index.html` | 生成好的成品页面（单文件，含全部样式、脚本、题库） |
| `index_template.html` | 页面源模板，题库位置留有待注入的标记 |
| `build_quiz.py` | 解析 docx 生成 `quiz_data.json`（题目分段 + 答案填充）、自检对齐 |
| `make_site.py` | 把题库注入模板，输出 `index.html` |
| `quiz_data.json` | 题库数据（40 题 / 79 空） |

## 重新构建

换了新的 docx 之后：

```bash
# 1. 修改 build_quiz.py 顶部的 DOCX 路径
python build_quiz.py     # 解析 + 自检（会打印对齐失败/重建不一致的题号）
python make_site.py      # 生成 index.html
```

`build_quiz.py` 会把每道题的答案按空格切开，再用贪心对齐把答案填回各个空位，最后把填好的句子与参考答案逐字比对（忽略标点），有任何不一致都会报出来。
